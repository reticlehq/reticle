### Fixed

- **`@reticlehq/engine`: a click whose store changed was graded `action-had-no-effect` when its visible update came late.** A video Pause button calls `pause()`, the app updates its store on the media `pause` event, and the label changes a moment later. `reticle_act_and_wait` saw no change inside the button and no request, so it reported `action-had-no-effect` and answered `unknown`, although `STATE_CHANGE paused false -> true` was in the same window. A store change or an app signal now counts as the action doing something when it is tied to the action: the `until` clause names its store path or signal, or nothing moved that path or fired that signal before the action. Background churn that was already moving still does not count, so a dead click on a busy page is still reported. Closes [#1531](https://github.com/reticlehq/reticle/issues/1531).
