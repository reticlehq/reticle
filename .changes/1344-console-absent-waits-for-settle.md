### Fixed

- **`@reticlehq/engine`, `@reticlehq/server`: a "no console errors" step passed when the error landed a moment after the action.** An absence was held for only 300ms after it first read true, so a click handler that logged an error 800ms later replayed as a passing step, and the run artifact reported an empty `consoleErrors` list. An absence is now held for at least a second and then until the page has gone quiet, within the step's timeout. A replayed step whose own window counted a console error cannot pass a console-absent expect, each step carries the console errors its window saw, and `evidence.consoleErrors` in the run artifact is built from them. An error scheduled more than a second after an otherwise silent action can still pass. Closes [#1344](https://github.com/reticlehq/reticle/issues/1344).
