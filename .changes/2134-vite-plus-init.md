### Fixed

- **`@reticlehq/init` — `reticle init` did not wire an app that uses Vite+ (`vite-plus`).** `vp create` and `vp migrate` write the app's plugins as `plugins: lazyPlugins(() => [...])`. Init did not read that form, so a migrated Laravel app got a manual step and no session. On a `vp create` React app, the config has a `lint.plugins` key first, and init wrote `reticle()` into that lint list and reported the step done. The app then never connected. Init now adds `reticle()` to the config's own plugin list, also inside `lazyPlugins`. It also detects an app that declares only `vite-plus`, reads the config that `vp dev --config` selects, and writes a new config that imports `defineConfig` from `vite-plus`. Closes [#2134](https://github.com/reticlehq/reticle/issues/2134).
