### Fixed

- **A failed lease or drive launch now names the Chromium path it looked for.** When Playwright's bundled browser is missing, the pooled launcher and the drive launcher replaced Playwright's error with the bare pinned install command and discarded the resolved executable path, the one fact that shows a daemon looking in a different browsers root than the shell that ran the install (a different `HOME` or `PLAYWRIGHT_BROWSERS_PATH`). Following the hint then succeeded in the shell and changed nothing, with no way to see why. The missing-browser message now reads "looked for <path>" alongside the pinned command, matching the evidence the lease preflight and `doctor` already print; the message is unchanged when no path can be resolved. Addresses the remaining report in [#691](https://github.com/reticlehq/reticle/issues/691).
