### Changed

- **`@reticlehq/init`, `@reticlehq/server` — agent hooks run the installed CLI directly and skip npx's start.** Every hook command was `npx -y @reticlehq/server@<version> hook …`. On a laptop, npx's own start took about 426 ms (p50) before the hook began. `reticle init` and `reticle hook install` now write `node "<bin>" hook … || npx -y …`. `<bin>` is the CLI that ran the install, written as `$HOME/…` when it is under your home folder. When that file is gone, node exits before it reads the payload and npx runs instead. Over 100 calls each, end to end through the shell: prompt hook p50 30 ms and p95 34 ms, post-tool hook p50 30 ms and p95 35 ms. On Windows the hooks keep npx alone, and Copilot's `powershell` field always uses npx, because Windows PowerShell 5 has no `||`. A hook that another machine already installed counts as installed, so a teammate's `init` does not rewrite the file with their own path.
