### Added

- **`server.json`: Reticle can now be published to the official MCP Registry.** The registry at `registry.modelcontextprotocol.io` is the index the directories read — Glama, `github.com/mcp`, mcp.directory and PulseMCP all ingest from it, and PulseMCP accepts nothing else — so a server absent from it is invisible to every one of them regardless of npm downloads. The manifest validates against the published schema, and `@reticlehq/server`'s `package.json` carries the matching `mcpName` (`io.github.reticlehq/reticle`) that the registry uses to prove the npm tarball belongs to the listing. Publishing is rejected if either moves without the other, so `scripts/set-version.mjs` now stamps both of `server.json`'s version fields with every release — the server version and the npm package version the registry resolves against.
