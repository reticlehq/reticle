### Added

- **`@reticlehq/server`: one "Reticle result" block at the end of every verification.** `reticle_verify` (`flows` and `change`) and `reticle_session { action: "end" }` now return `reticleResult`, a short markdown block built by the server from the verdicts it holds: a verdict line in three words only (proved, not proved, failed; one undecided check is never proved), the yes / no / undecided counts, the journeys covered, what it measured (checks, flows replayed, time), screenshot paths, and one last line about the platform. Linked, that line links the run on the dashboard; not linked, it says what the platform adds and how to connect, once per result. The skill now tells agents to paste the block verbatim instead of paraphrasing a verdict into a pass. A `change` verdict decided above the suite (uncovered files, a disagreeing channel) retitles the block, so a nested "proved" can never sit under an outer `no`.
