### Changed

- **`@reticlehq/server` — advisories arrive as one `notices` list, each said once per agent session.** The feedback ask, the founder invitation, the platform line, the update note, the pool-lease reminder and the session-age warning used to ride as separate keys, and the ones that were not one-shot repeated on every call. An agent's own call now carries them as one-line `notices`, each at most once per MCP connection; `next` is said only when it says something new; the throttled-tab paragraph is said once (the `session.throttled` flag still rides on every result) and the version-skew paragraph shrinks to one line after the first time. The feedback family is asked at most once per session, and gated where it is taken, so the feedback-rate denominator counts only asks an agent saw. An empty session list answers in one sentence plus its executable `next_action`. `detail: "full"` keeps the old keys. A `version_skew` report is never folded: it is decisive, so it keeps its own key and reaches the agent on its next result, whatever the tool.
