### Fixed

- **`@reticlehq/server`: `verify <url> --expect` waits for its predicate, up to `--timeout`.** It called the one-shot assert about a second after navigating and dropped `--timeout`, so a predicate naming a request the page makes shortly after load came back `unknown` with `window_closed_early`. `--expect` now calls `reticle_assert` with `timeout_ms` set to the `--timeout` budget (default 4000 ms), so the grade, journal entry and `verifiedReason` are still the assert's. A budget longer than one assert call (55 s) first waits out the remainder with `reticle_wait_for`, then asserts. A refusal on that path is printed as the refusal sentence. `verify --help` and the CLI docs say `--timeout` applies to `--expect`. Closes [#1533](https://github.com/reticlehq/reticle/issues/1533).
