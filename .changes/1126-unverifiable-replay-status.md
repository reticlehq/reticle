### Fixed

- **`@reticlehq/server`, `@reticlehq/core`: `reticle_flow_replay` and verification suites returned `status: "ok"` for runs that were never graded.** A replay that could not start or finish because of missing required secrets, an unmet precondition, or a lost document connection answered `status: "ok"` with an `unverifiable` caveat, which downstream agents, CI runners, and dashboards interpreted as a successful verification. Those ungraded paths now return `status: "unverifiable"`. In verification suites they count toward neither passed nor failed flows and resolve the suite to an unverifiable verdict, and in persisted run artifacts they map to skipped flows with the exact failure reason preserved. Closes [#1126](https://github.com/reticlehq/reticle/issues/1126).
