### Added

- **`@reticlehq/server` — a result tells an agent when it repeats the same call with the same result.** Agents made the same call five times or more in a row, and each answer was the same as the last. Now, on the third call in a row from one agent connection with the same tool, the same arguments and the same outcome, the result carries one `repeatHint` line that says what to try instead. A repeated `no_match` refusal says to take one `reticle_look { action: "find" }` and use a ref from it. A repeated verdict names the verdict and its own `because`. A `reticle_look` with the same answer says that the page did not change. When there is nothing specific to say, the line says only that the call was repeated with the same result. The hint comes once in a streak. It never changes the verdict and never blocks the call. Each agent connection is counted alone, and only its last call is kept.
