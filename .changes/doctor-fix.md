### Added

- **`@reticlehq/server` — `reticle doctor --fix` repairs a half-done install.** It applies only the repairs that change Reticle's own state: it deletes the pid file of a stopped daemon, stops a Reticle daemon that holds the port and does not answer, installs the pinned Chromium when no browser can stand in, and runs `reticle setup mcp` when an agent on the machine does not have Reticle. Then it runs the checks again, and prints `fixed`, `nothing to do` or `still needs: <step>` for each row. It exits `0` only when no row fails. A second run changes nothing. A plain `reticle doctor` now has an `mcp` row, and ends with the number of rows that `--fix` can repair.
