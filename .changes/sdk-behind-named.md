### Added

- **`@reticlehq/browser` + `@reticlehq/server`: you can see which SDK the page is running.** The overlay's settings name the SDK version the page actually loaded, and a page a minor release or more behind the daemon is named — to the agent once, on its next tool result, and to the person on the overlay — with the command that brings it up. A page that is only a patch apart stays silent, and the notice never replaces the advice on an error it did not cause.
