### Fixed

- **`@reticlehq/engine`, `@reticlehq/browser` — a `text` predicate's `satisfies` was graded against the first 80 characters of the text, not the text.** The page describes every element with a display-sized `text` (80 characters and an ellipsis), and `satisfies` read that: an exact `oneOf` or an end-anchored `matchesPattern` on a long consent legend failed while a role/name assertion on the same fieldset passed, and a relative `changed` could not see an edit past character 80. The `match` command now takes `fullText`, which the predicate sets when it carries a `satisfies` (and the before-reading for `changed`/`unchanged`/`increased`/`decreased` sets the same way), so the property is judged on up to 4000 characters of the text. A longer text is not graded on the part that was read: the verdict is `inconclusive` and says so. The match a verdict returns, and the text a failure quotes, stay display-sized. Closes [#1322](https://github.com/reticlehq/reticle/issues/1322).
