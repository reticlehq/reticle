### Added

- **`@reticlehq/server` — every tool call is kept in `.reticle/episodes/`, with its whole result and what it did to the page.** The journal kept the actions that drove a page, with a short summary of each. It did not keep the reads, the answers the agent got, or the calls made before a tab connected. Now each agent connection writes `.reticle/episodes/<connection>.jsonl`. The first line records the git HEAD, the uncommitted change for each file, and the user's request. Each line after it records one call: the tool, its arguments, its whole result or error, the start and end time, the tab, the agent, and the page events that the call caused. Typed values are removed, as in the journal. A field longer than 200,000 characters keeps its start and is named in `truncated`. The file stays on your machine. It is not committed, the sync never reads it, and retention removes old files with the other evidence. It obeys the journal switch: `RETICLE_JOURNAL=0` or `"journal": false` in `.reticle.json` turns it off. `"sync": { "episodes": true }` in `cloud.json` is reserved for a later upload, which also needs a workspace that agreed to share its data.
