### Added

- **Element predicates can now assert geometry.** An `element` predicate gains three fields, measured in the page from the same box `reticle_look` reports: `fullyInViewport` (the whole box inside the viewport and every clipping ancestor, where `state: "inViewport"` asks only that some of it shows), `textClipped` (content beyond the client box under `overflow: hidden | clip`, or `text-overflow: ellipsis` in effect), and `overlaps` (another element as a query, whose box this one must intersect; assert the negative with `not`). The browser stamps the measured geometry on the descriptor only when a predicate asks, and failures report the measured box, the viewport, and the overflow amounts instead of a bare mismatch. Addresses [#1539](https://github.com/reticlehq/reticle/issues/1539).
