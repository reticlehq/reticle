### Fixed

- **`@reticlehq/engine`, `@reticlehq/server` — an empty `allOf` was a green that rested on nothing.** `{ kind: "allOf", predicates: [] }` parsed, evaluated true and reported `verified: "yes"` for a drive that asserted nothing — vacuous truth, every member holding because there were none. Nobody writes that by hand; an agent building `predicates` by mapping over a list of channels emits it the moment that list comes back empty. The schema now refuses an empty combinator, and a combinator with no branches grades at the floor so a constructed one still trips `vacuous_grade`.

- **`@reticlehq/server` — a run artifact said every check read the DOM.** Every folded check was stamped `kind: "element"`, including the ones whose own `grade` in the same object said `net` or `state`, because the journal had no kind to carry. Channel routing reads that field, so a network verdict arrived as a UI verdict. Both verdict sites now record it and the run carries it through; a record written before the field existed stays absent rather than being given a kind nobody observed.

- **`@reticlehq/server` — an ambiguous anchor replayed the first match and called it green.** When a testid matched several live elements, replay acted on one of them and returned `ok` with a note; the verdict reads drift and `ok` and never reads a note. A replay that clicked a different row than the recording reported success — in the feature whose entire claim is "it did what it did before". It is now drift, with its own reason so healing can propose a narrower anchor, and the action is not dispatched at all.

- **`@reticlehq/core` — `attrs: ["name=value"]` could only ever prove presence.** The element query accepts attribute NAMES and projects them onto the match; it has never filtered on a value. A `name=value` string silently lost its value half, so asserting that a job had reached `complete` passed while the job was still running. It is now refused, with a message naming the supported shape, and the docs describe the item shape they previously omitted.

- **`@reticlehq/engine`, `@reticlehq/server` — a verdict was served over a wire the tools themselves distrusted.** `verify` printed `verified: yes` and exited 0 while its own evidence reported a version skew between the page SDK and the daemon, and `reticle_session` warns that under skew dispatched and settled may be silent no-ops. A skewed link now yields `unknown` with a reason naming the mismatch — nothing about the app was disproved, the evidence underneath it is what is in doubt.

- **`@reticlehq/server` — a third-party beacon could keep a window open forever.** The settle check dropped the dev toolchain's own traffic but not other people's hosts, while the contradiction rules dropped both. An app embedding a vendor SDK that polls its own telemetry endpoint never settled, so every assertion on it returned `unknown` whatever the feature under test was. Same-origin traffic is deliberately untouched: nothing in a URL separates an app's telemetry from its work.

- **`@reticlehq/server` — a journal read could take the daemon down.** An oversized session journal reached the read syscall with a length it cannot accept, which aborts the process rather than throwing — so one large file stopped every session on the machine, including unrelated ones. Reads are now bounded and malformed offsets refused at the seam.

- **`@reticlehq/core`, `@reticlehq/server` — a flow file from another format read as a corrupt one.** A flow carrying a different `version` failed the schema like a typo and the reader answered "malformed — fix or regenerate it", which is the one thing to avoid doing to an intact file written by a newer or older Reticle. It now reports a version mismatch and says which version it found and which it reads.
