### Fixed

- **`@reticlehq/server`: a command that times out on a background browser tab says the tab is hidden.** A hidden web tab keeps reporting in while its throttled frames miss the command, so the timeout read as a one-way transport fault and told the agent to debug the bridge-to-page socket. When the SDK reported an ordinary browser tab and the page last reported itself hidden, the message now says it is a background tab and names the way out, `reticle_lease { action: "acquire", url }`. A visible page that is heard from and still not answering keeps the transport advice, and the Tauri hidden-before-load advice is unchanged. Closes [#1416](https://github.com/reticlehq/reticle/issues/1416).
