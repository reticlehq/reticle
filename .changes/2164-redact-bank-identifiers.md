### Security

- **`@reticlehq/core` — bank-transfer identifiers (`iban`, `accountNumber`, `routingNumber`, `sortCode`) were not redacted by the wire key rule.** `PAYMENT_FIELD_WORDS` already treated IBAN, account number, routing number and sort code as payment-sensitive so the Harness refused to type into them, but `SENSITIVE_KEY` did not cover them. A bank-transfer or payout request body carrying `iban`, `accountNumber`, `routingNumber` or `sortCode` reached the agent transcript and the on-disk journal (`~/.reticle`) in clear. `SENSITIVE_KEY` now redacts `(?:^|[-_])iban(?=$|[-_])`, `account[-_]?(?:number|num|no)(?=$|[-_])`, `routing[-_]?number(?=$|[-_])` and `sort[-_]?code(?=$|[-_])`, while leaving `account`, `accountId`, `accountType`, `accountName`, `routingPath`, `sortOrder`, `sortBy` and `code` visible. Closes [#2164](https://github.com/reticlehq/reticle/issues/2164).
