### Added

- **`@reticlehq/server`, `@reticlehq/init` — the installer and `reticle init` say which agents connected, and an old Claude Code entry is named.** The one-line installer ran `reticle setup install` with its output in a file, so the wait for the agents never ran. The installer now runs `reticle setup wait-agents` as its last step, with the terminal attached, only when a person is at a terminal and not in CI. `reticle init` prints the same "Your agents:" block after its restart notice, and runs the same 60-second wait at a terminal. A Claude Code user-scope `reticle` entry that runs `npx @reticlehq/server` with no version starts whatever version npx has in its cache. `reticle setup mcp`, `reticle init` and the `launcher` row of `reticle doctor` now name that entry as stale, with the two commands that replace it. Nothing removes it, and `reticle doctor --fix` prints the step.
