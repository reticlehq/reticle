### Fixed

- **`@reticlehq/engine` — writes that an assertion counted were called a double submit.** Two clicks that each saved to the same endpoint with the same body, asserted with `{ kind: "net", method: "POST", urlContains: "/notification-preferences", count: 2 }`, passed the check but came back `unknown` with `duplicate-request` ("one user action was performed"). Now a `net` clause with `count: N` makes up to N landed writes to its endpoint the declared consequence, so the verdict is `yes`. A write past N is still reported. One click that the app submits twice leaves the same evidence as two clicks, so with `count: 2` it is not reported either, until the actions are counted (the second half of [#2273](https://github.com/reticlehq/reticle/issues/2273)). Part of [#2273](https://github.com/reticlehq/reticle/issues/2273).
