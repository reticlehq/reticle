### Fixed

- **`@reticlehq/computer` — on Linux, an action in LibreOffice timed out, and the words of its documents were not read.** The AT-SPI helper read every item of every closed menu, about 2,000 elements in LibreOffice Writer, and it read the state of each element up to eight times. One read took 3.5 s. An action reads the application before and after, so it took longer than the bridge waits for a command. The helper now reads only the items of an open menu, and says how many items a closed menu has. It reads the state of each element once. A read of Writer now takes 0.8 s, and its snapshot costs about 3,800 tokens, not 17,900. Also, a static text gives its words as its value, as on macOS. A LibreOffice paragraph has no name, so before this fix the text of a document was empty in the tree, and a check on it could not pass.
