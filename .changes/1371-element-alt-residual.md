### Added

- **`@reticlehq/engine`: an `element` predicate can check an image's `alt` next to a locator that does not read it.** `{ kind: "element", query: { testid: "hero-image", alt: "Product photo" } }` was refused with "the element locator ignores `alt`", and so was `scope` + `self` + `alt`, so checking one attribute on one specific image meant a workaround. `alt` is now compared against the image's `alt` attribute: a matching `<img>` passes, a different alt grades `no` with the alt that was found, and `alt: ""` passes only on a decorative image, never on one with no alt attribute at all. On an element that is not an image the predicate is still refused, now with a hint to assert `name` instead, because a button has no alt and "no" would read as "the alt is wrong". Closes [#1371](https://github.com/reticlehq/reticle/issues/1371).
