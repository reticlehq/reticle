### Fixed

- **`@reticlehq/server` — `reticle gate` blamed a missing flow when the saved flows carry no source locations.** On a stack without source stamping (Vue, for one) every changed component was listed under "no saved flow drives it", even when a flow had driven it and passed. When flows exist but none carries a source location, the Stop-hook message now says the gate cannot match those flows to a changed file and names `@reticlehq/vite-plugin` for JSX and Svelte files (which it can stamp) or says source stamps are not available for that framework yet, and the gate's JSON output carries `flowsWithoutSources: true`. Closes [#1604](https://github.com/reticlehq/reticle/issues/1604).
