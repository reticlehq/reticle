### Added

- **`@reticlehq/server` — `reticle_act_and_wait { durable: true }`.** After a `yes`, reloads the page and requires the consequence to hold on the fresh document: "it saved", not "the UI said so". A consequence that reverts before the action finishes now fails too.
- **`@reticlehq/server` — an app-wide coverage ledger.** `reticle_coverage { app: true }` reports six levels, each with what is missing: routes reached, controls touched, controls proved, journeys completed, writes whose failure path was driven, and app functions that ever ran (V8 coverage from a browser Reticle drives).
- **`@reticlehq/server` — `reticle_crawl { exhaustive: true }`.** Walks every state reachable from the start page (replaying the path to each one, treating repeated rows as one control, filling forms first), then drives every write it found with the request failing and reports an app that shows success over a failed write. The run is folded into the ledger, and `reticle gate` blocks when a level falls below its best or a changed file never ran.
- **`@reticlehq/server` — the autonomous drive goes deep.** It finishes the journey it started, can go back from a dead end, fills a field from `RETICLE_SECRET_<FIELD>` when set, and reports the pages it reached. The crawl follows controls its own clicks reveal.
