### Added

- **`@reticlehq/server` — `reticle_act_and_wait { durable: true }`.** After a `yes`, reloads the page and requires the consequence to hold on the fresh document: "it saved", not "the UI said so". A consequence that reverts before the action finishes now fails too, and a reloaded page that cannot answer is `unknown`, never `no`.
- **`@reticlehq/server` — an app-wide coverage ledger.** `reticle_verify { action: "coverage", app: true }` reports six levels, each with what is missing: routes reached, controls touched, controls proved, journeys completed, writes whose failure path was driven, and app functions that ever ran (V8 coverage from a browser Reticle drives). Code coverage is collected only once something asks for it, the first coverage request or an exhaustive crawl, so pages you drive without asking run at full speed.
- **`@reticlehq/server` — `reticle_verify { action: "crawl", exhaustive: true }`.** Walks every state reachable from the start page that it can tell apart by route and control names (replaying the path to each one, treating repeated rows as one control, filling forms first, and typing a `RETICLE_SECRET_<FIELD>` value only on the origin it started on), then drives every write it found with the request failing and reports an app that shows success over a failed write. A write counts as branched only when its request was actually sent and broken. The run is folded into the ledger, and `reticle gate` blocks when a level falls below its best or a changed file never ran; a changed file whose coverage predates its edit is named as `coverageStale` rather than read as covered. A drop you intended, such as a control removed on purpose, is accepted with `reticle gate --accept-coverage`.
- **`@reticlehq/server` — the autonomous drive goes deep.** It finishes the journey it started, can go back from a dead end, fills a field from `RETICLE_SECRET_<FIELD>` when set, and reports the pages it reached. The crawl follows controls its own clicks reveal, and `confirmDangerous` does not carry over to them.
