### Fixed

- **`@reticlehq/browser` — a synthetic `press` now does what the key does in a browser.** A synthetic key event has no default action, so Enter on a native button did not activate it, Enter in a form field did not submit the form, Space did not click a button or toggle a checkbox, and Tab did not move focus. The app received the key and nothing followed, and a correct app was verified `no`. In act and in flow replay, a press now runs each browser default, only on the elements where a browser runs it, and only when the app did not cancel the key. A `role="button"` element still gets no default, as in a browser. Space is now held to the destructive-action rule, like Enter and a click. A real-input press on a leased tab is unchanged. Refs [#1519](https://github.com/reticlehq/reticle/issues/1519).
