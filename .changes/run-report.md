### Added

- **`@reticlehq/server` — the call that ends an agent's run now carries a run report.** `reticle_session { action: "end" }`, `"yield"` and `reticle_lease { action: "release" }` answer with `runReport`: every claim the run checked with its verdict and one piece of evidence, the claims that did not hold, the flows saved and replayed, the memory written and read, and the time to the first verdict. `runReport.markdown` is the same report as text, and `runReport.instruction` tells the agent to end its answer with it, unchanged. Before this, an agent that ended by releasing its tab got no word about the run, and wrote its own summary. When the project is not linked to Reticle Cloud, the report has one labelled line that says what the dashboard adds and what it costs. `RETICLE_NO_UPSELL` turns that line off.
