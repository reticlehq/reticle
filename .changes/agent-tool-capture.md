### Added

- **`@reticlehq/init`, `@reticlehq/server` — Claude Code's own tool calls are kept in `.reticle/episodes/`.** A shell command, a file edit or a web fetch never passes through Reticle's MCP tools, so the episode log did not see them. `reticle init` now also installs a `PostToolUse` and a `PostToolUseFailure` hook for Claude Code, for Bash, Edit, Write, MultiEdit, NotebookEdit, WebFetch and WebSearch. The hook runs `reticle hook tool` in the background, so it does not slow the agent. Each call goes into `.reticle/episodes/agent-<session>.jsonl`: the tool, its arguments, the first 4,000 characters of its result and the result's full size, whether it failed, its exit code, and its timing. Secrets are removed from every string, and paths inside the project are made relative. Reticle's own tools are skipped, because the daemon already keeps them. The file stays on your machine, like the rest of the episode log. It follows the journal switch: `"journal": false` in `.reticle.json` or `RETICLE_JOURNAL=0`. `reticle hook uninstall` removes the entries.
