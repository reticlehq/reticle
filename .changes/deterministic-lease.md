### Added

- **`@reticlehq/server` + `@reticlehq/browser` — a deterministic lease gives the same pixels and text on every run.** A canvas game or an animation drew something different each time, because time and randomness differed. `reticle_lease { action: "acquire", deterministic: { seed?, platform? } }` installs a seeded `Math.random` and `crypto`, and a virtual clock for `Date`, `performance.now`, the timers and `requestAnimationFrame`, before any page script runs. `reticle_clock { stepFrames: N }` moves that clock N frames of 16.67 ms. The device pixel ratio is 1, and `platform` sets `navigator.platform` for pages whose keyboard labels differ between Mac and Linux. The SDK keeps real time on such a tab, so reads, clicks and verdicts still work. Leases without the option do not change.
