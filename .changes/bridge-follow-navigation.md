### Added

- **`@reticlehq/server` — a hosted drive can follow its own navigation to another origin.** A bridge admits a page only from the origins it was built with. A drive that started on `www.wikipedia.org` and clicked through to `en.wikipedia.org` lost its session at the new page, because the new origin was refused. `Bridge` now takes a `followNavigation` option. When it is set, a page on a new origin can continue a session only if all of these are true: the bridge already admitted that session from an allowed origin, the page passed the token or nonce check, the page address is on the origin it dialled from, and `followNavigation({ sessionId, from, to, url })` returns `true`. A new origin can never start a session. Without the option nothing changes.
