### Added

- **`@reticlehq/init` — `reticle init` wires the web build of an Expo app.** An Expo app used to be read as plain HTML and handed a snippet for an `index.html` Metro never serves, and the no-session scan never checked Expo web's port. `init` now detects Expo from the `expo` dependency and writes `reticle-dev.web.ts`, the dev-only connect, beside an empty `reticle-dev.ts`. It imports `./reticle-dev` from the expo-router root layout (`app/_layout.tsx` or `src/app/_layout.tsx`) or from `App.tsx`. Metro resolves that import to the connect on web and to the empty module on iOS and Android, so the native bundles never load the SDK. The pairing token and bridge URL go into the git-ignored `.env.local` as `EXPO_PUBLIC_RETICLE_TOKEN` and `EXPO_PUBLIC_RETICLE_URL`, the only variables Expo inlines into app code. Port 8081 joins the dev-server scan and is Expo's framework default. Closes [#1707](https://github.com/reticlehq/reticle/issues/1707).
