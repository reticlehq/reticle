### Added

- **`@reticlehq/init`, `@reticlehq/server` — the episode log names the agent's model, and keeps Codex, Cursor and Gemini CLI tool calls.** The model comes from the hook payload, where the agent sends one. Claude Code sends it only when a session starts and when the model changes, so `reticle init` also installs a `SessionStart` and a `PostModelSwitch` hook. Each of these writes an `agent_model` record. Cursor and Codex send the model with every hook, so each of their tool records carries it. Gemini CLI documents no model field. New post-tool hooks follow each vendor's hook reference: Codex `PostToolUse` for `Bash` and `apply_patch`, in the background; Cursor `postToolUse` and `postToolUseFailure` for `Shell`, `Write` and `Delete`; Gemini CLI `AfterTool` for `run_shell_command`. Cursor and Gemini CLI document no background option, so the agent can wait for each hook run. Windsurf, VS Code Copilot, Copilot CLI and Factory Droid keep only the prompt hook until their post-tool formats are checked.
