### Added

- **`docs`: documented `scroll` by `fraction` with an example.** While `scroll` steps down by default, setting `fraction` (a number from `0` to `1`) jumps directly to that percentage of the container's or page's scrollable height. Added a dedicated section and JSON example in `docs/actions.mdx`. Closes [#1260](https://github.com/reticlehq/reticle/issues/1260).
