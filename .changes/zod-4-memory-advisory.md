### Security

- **`@reticlehq/core`, `@reticlehq/engine`, `@reticlehq/server`, `open-verification` — moved from zod 3 to zod 4.6.6 or later ([GHSA-mrhx-c7xc-m3w5](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5)).** zod below 4.6.6 checked every item of a list before it checked the list's length. A message with a very large list could use all the memory of the bridge or the MCP server. zod 3 has no fixed release. Now Reticle refuses an oversized list before it checks one item. The bridge limit of 1 MiB for each message stays. The wire format does not change. Validation messages use the zod 4 words, for example `Invalid input: expected record, received number`. If your own code composes a schema from `@reticlehq/core` with zod 3, move that code to zod 4 when you upgrade.
