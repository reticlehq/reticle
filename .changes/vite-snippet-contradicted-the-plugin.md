### Fixed

- **The Vite snippet for a manual install told you to do the opposite of what the codemod does, for a reason the plugin contradicts.** It said to keep `reticle()` last in the `plugins` array "so it sees the output of your other plugins", and showed it last. The plugin declares `enforce: 'pre'`, so Vite runs it before every normal plugin wherever it sits: the position does not matter, and the stated reason is backwards, because `pre` means it sees your source rather than another plugin's output. Meanwhile `reticle init` writes it first when it patches the config itself, and the framework docs show it first, so the one path a reader takes by hand was the one that disagreed with every other path. That path is the one reached when the config cannot be auto-patched, which is exactly where a reader is least able to spot the difference.
