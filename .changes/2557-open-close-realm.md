### Added

- **`@reticlehq/server` — an agent opens a realm as a session, and closes what it opened.** `reticle_open_realm { realm: "computer", app, launch? }` joins a desktop application (it runs `reticle-computer` of this release), and `{ realm: "browser", match }` joins a tab of the person's browser, as `reticle_attach_tab` does. Both answer with the `sessionId`. `reticle_close_realm { sessionId }` ends a session that the same agent opened, and refuses any other. When the agent leaves, every realm it opened is closed after a 30-second grace. Reach both with `reticle_run`. A tool call does not show the approval prompt that an agent shows before a terminal command, so an agent can open only an application that the person listed in `~/.reticle/computer.json` (`{ "open": ["Mail"] }`). Closes [#2557](https://github.com/reticlehq/reticle/issues/2557).
