### Fixed

- **`@reticlehq/browser`, `@reticlehq/core`, `@reticlehq/server` — a recorded click on an element with no accessible name survives a change that moves its line.** An element with no accessible name, such as a list item, was saved as a component and source-line anchor. The line belongs to the implementation that was recorded, so a correct change that moved it left nothing to find, and the replay failed a correct app. The act result now carries the element's own short text (`ownText`), a saved component anchor keeps it as `text`, and a component query with `text` keeps only the elements whose own words are that text, at the recorded line or, when that line is gone, anywhere in the component. An app whose SDK is older than this change answers the query as it did before.
