### Added

- **`@reticlehq/server` — a leased tab can be handed browser permissions.** UI that only renders once a permission is decided, like a "you are here" map or a paste button, could not be reached in a lease, because nothing granted or cleared a permission. `reticle_lease { action: "acquire", permissions: ["geolocation"] }` now grants on the app's origin before the first navigation. A lease that is already open keeps its grants, since it may be another agent's tab, so changing them is release and acquire again. One limit is reported rather than hidden: Playwright's headless shell never passes a notifications grant on to `Notification.permission`, so when you ask for `notifications` the lease reads the value back from the page and says so in `hint`. Closes [#1370](https://github.com/reticlehq/reticle/issues/1370).
