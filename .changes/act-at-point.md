### Added

- **`@reticlehq/core`, `@reticlehq/browser`, `@reticlehq/server` — `click`, `dblclick`, `hover`, `tap` and `drag` act at a point inside the element.** Before, each pointer action landed at the centre of the element's box. A canvas has no child elements, so a game or a drawing on a canvas could not be driven. Pass `args.at: { x, y }`, each a fraction of the element's box from 0 to 1 (a value outside is clamped to the edge). A drag also takes `args.to: { x, y }`, the end point in the drop target, or in the source when there is no drop target, so a drag can move inside one canvas. The page events and the real pointer both land at the point, and `clientX`/`clientY` are the point. A point that is not two numbers is refused by name. Without `at`, every action is the same as before.
