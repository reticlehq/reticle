### Added

- **`@reticlehq/server` — `reticle verify <url> --against <reference-url>` reports what a change altered in what users see.** A saved flow checks the consequences its author thought of, and not that all other text stayed the same. `--against` drives both running builds (for example a pull request preview and production) with the same actions: each saved flow one step at a time, and the deterministic explorer of `reticle_verify { action: "crawl", exhaustive: true }`. After each step it compares the visible content: names, text, values and control states. Lines that also change between two runs of the reference are ignored. A step the candidate cannot do is a difference. Each difference prints its actions and its `-` and `+` lines, `--results-json` gives each one a stable id, and the command exits `1` when anything differs. The explorer now gives each text field its own value and waits a short time after each click. Closes [#2190](https://github.com/reticlehq/reticle/issues/2190).
