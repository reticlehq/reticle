title: reticle license

`reticle license` reports whether an enterprise license is active. It resolves entirely from the environment. Nothing leaves the machine.

```bash
npx @reticlehq/server license
```

No flags.

## What it prints

One `reticle_license` JSON line, on stderr. On a checkout with no issuer key configured:

```json
{
  "t": "2026-08-15T18:42:26.758Z",
  "event": "reticle_license",
  "contact": "hey@reticle.sh",
  "status": "eval",
  "detail": "evaluation mode (no issuer key configured)"
}
```

| `status`  | Meaning                                             |
| --------- | --------------------------------------------------- |
| `active`  | A valid license is present                          |
| `eval`    | Evaluation mode. No issuer key is configured        |
| `missing` | No license, and the build expects one               |
| `expired` | The key verified, but its expiry has passed         |
| `invalid` | The key was rejected, or the build is misconfigured |

`detail` is a sentence explaining the status. An active license also carries `licenseId`, `org`, `plan` and `expiresAt`.

## Exit codes

Always `0`.

## Worked example

```bash
npx @reticlehq/server license 2>&1 | jq -r .status
```
